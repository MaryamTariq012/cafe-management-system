# Cafe Management System

A modular desktop GUI application developed in Java leveraging core Object-Oriented Programming (OOP) concepts.

## Features
- Dynamic Dashboard UI designed using NetBeans GUI Builder (.form components).
- Automated store inventory tracking and customer transactional billing.
- Implemented clean encapsulation bounds, class inheritance trees, and polymorphic behaviors.
- File-handling streams integrated to persistently manage and log daily sales records.

## Tech Stack
- Language: Java
- Framework: Java Swing / AWT (GUI)
- IDE: NetBeans
- Concepts: Object-Oriented Programming (OOP), File Handling (I/O Streams)
